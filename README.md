# MongoDB College Library Management System

## 1. Project Description

This project is a simple College Library
Management System developed using MongoDB.

It stores information about books, students
and book borrowing records.

## 2. Technologies Used

- MongoDB Community Server
- MongoDB Compass
- MongoDB Shell (mongosh)

## 3. Database Structure

Database Name: CollegeLibrary

Collections:
1. Books
2. Students
3. BorrowRecords

## 4. Operations Performed

- Insert: Adds book and student records.
- Find: Displays stored records.
- Update: Changes book availability.
- Delete: Removes student records.
- Count: Counts the total books.

## 5. How to Run

1. Install MongoDB Community Server.
2. Install MongoDB Shell.
3. Start MongoDB service.
4. Open Command Prompt.
5. Type mongosh.
6. Run the commands in database/library.js.
